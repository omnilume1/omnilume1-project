# Supabase Database Files

This folder contains the **complete database definition** of the shared Supabase project (project ref: `cqmqliqfrasaxzuyeshc`), extracted automatically with `pg_dump` so it can never be lost.

## Contents

| File | Purpose |
|---|---|
| `01_schema.sql` | **Authoritative rebuild file.** Full schema: all 10+ tables, columns, indexes, functions, and 32 RLS policies. Generated by `pg_dump --schema-only`. |
| `POLICIES.md` | Human-readable listing of every Row Level Security policy (for review only — do not execute). |

## How to rebuild the database on a fresh Supabase project

1. Create the new project
2. Open **SQL Editor**
3. Paste the entire contents of `01_schema.sql` and run it
4. Done — all tables, policies, and functions are recreated

## Rules for future database changes

- Every schema change (new table, new column, new policy) must also be reflected here
- Easiest workflow: run the change in Supabase SQL Editor, then regenerate `01_schema.sql` with pg_dump and commit both
- Never put database passwords, service-role keys, or connection strings in this folder or anywhere in the repo
